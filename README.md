# dev-tools

Development helpers shared by projects, each in its own folder with its README and tests:

- [gitfast](gitfast/README.md): Git history rewriting from scripts without a checkout and without
  a `git` process per file or commit; `fold-into.sh` folds the working tree's changes into an
  earlier commit.
- [codescene](codescene/README.md): local checks of C/C++ code by CodeScene's Code Health rules
  (lizard-based), and of the braces of the `if`s' bodies.
